"The kgame" is an interactive text-based adventure game where players dive into chemistry concepts, experiment with combinations, and navigate a narrative-driven world.

Why I Built It I built this project because I wanted to mix my two favorite things: coding and chemistry. It's a creative way to explore programming logic while bringing chemical interactions to life through storytelling.

How to Run / Play

Option 1: On Replit

Open the project link on Replit.
Click the Run button at the top of the workspace.
Play directly in the Replit console!
Option 2: Locally in Your Terminal

Clone or download the repository.
Open your terminal in the project directory.
Run the project using your C# / .NET environment:
dotnet run
